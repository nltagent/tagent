# telegram-agent

Лёгкий модульный Telegram-бот-агент: справочник с поиском в
интернете, память и ветки диалогов, напоминания, мониторинг сервера,
и навык работы с GitHub — всё через LLM (OpenRouter, clavis.to или
любой другой OpenAI-совместимый провайдер, включая несколько сразу).
Разворачивается в Docker на Railway (бесплатный/пробный тариф) или
локально в Codespaces. Только stdlib Python — минимум внешних
зависимостей.

## Возможности

- 👥 **Многопользовательский с ролями** — user/vip/creator, заявки на
  доступ с одобрением создателем (`/approve`, `/deny`, `/block`);
  каждый пользователь работает ТОЛЬКО со своими ключами (LLM, поиск,
  GitHub) и своей самопамятью — никаких общих или чужих ключей.
- 💬 **Диалог с LLM** — модель сама решает, когда нужно поискать в
  интернете; помнит факты о себе/вас между любыми диалогами;
  несколько параллельных веток диалога с независимой историей.
- 🔍 **Поиск в интернете** — Keenable или self-hosted SearxNG,
  переключается на лету, с retry на временных сбоях.
- ⏰ **Напоминания** на естественном языке ("через 10 минут",
  "завтра в 9:00").
- 📊 **Мониторинг сервера** и живая самопроверка всех навыков по
  команде.
- 🤖 **Несколько LLM-провайдеров и моделей одновременно** —
  добавляйте ключи от разных агрегаторов, переключайтесь командой;
  список бесплатных моделей определяется "умным" анализом, а не
  жёсткой схемой одного провайдера.
- 🐙 **GitHub-навык** — закоммитить готовый код в ветку, или попросить
  модель саму переписать существующие файлы по инструкции — оба без
  клонирования репозитория, одним атомарным коммитом.
- 📝 Заметки.

Полный список команд с примерами — `docs/COMMANDS.md` (или `/help`
прямо в боте).

## Быстрый старт

1. `docs/SETUP.md` — как развернуть: локально, в Codespaces (бот +
   SearxNG вместе через `docker-compose.yml`), и в проде на Railway
   (три сервиса: бот, SearxNG, Cron Job).
2. `.env.example` — полный список переменных окружения с комментариями.
3. `tests/run_tests.sh` — прогнать тесты перед деплоем (не нужны
   реальные ключи).

## Документация

| Файл | Что внутри |
|---|---|
| `docs/SETUP.md` | Развёртывание: локально, Codespaces, Railway (бот + SearxNG + Cron Job) |

заметите расхождение, это баг документации, дайте знать.

## Структура репозитория

```
src/            — весь код бота (см. docs/ARCHITECTURE.md)
tests/          — юнит-тесты (unittest, всё замокано)
docker/         — Dockerfile бота
searxng/        — Dockerfile + settings.yml для SearxNG (отдельный Railway-сервис)
scripts/        — вспомогательные скрипты (регистрация вебхука)
docs/           — документация (этот список)
docker-compose.yml — локальная проверка бота + SearxNG вместе
.env.example    — все переменные окружения с комментариями
```
